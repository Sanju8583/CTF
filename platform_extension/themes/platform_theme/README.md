# Platform Theme

The included CTFd theme provides a cyber-inspired public interface with
responsive layouts, custom navigation and homepage templates, and light/dark
color modes. It inherits CTFd's core templates for pages it does not override.

## Activate

The Compose override makes this example theme available as
`platform_theme`. Select it under **Admin Panel → Config → Theme** and save.
It is not enabled by default.

The color-mode button in the navigation uses CTFd's built-in preference
handling and remembers each visitor's choice in their browser.
